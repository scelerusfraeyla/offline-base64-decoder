# offline (html) Base64 decoder 

a single-file html webpage with javascript built-in: offline [Base64](https://en.wikipedia.org/wiki/Base64) decoder &amp; image converter.

## how to use
* download the HTML and open it in any browser.
* that's it. everything runs locally in the browser, nothing is uploaded elsewhere.
* nothing is persisted: decoded output is held in memory only, so download any file you want to keep before refreshing or closing the page.

## features
* decodes base64 strings and data URIs
* previews images (png, jpg, gif, webp, svg) directly in the page
* shows decoded text and file metadata (type, size)
* one-click download of the decoded file

## storage & privacy
* no localstorage / sessionstorage is used.
* no cookies set anywhere in the code.
* no data is collected, transmitted, or logged in any form.
* no server storage of any kind. you can run it fully offline.
* plain html + css + javascript, no dependencies & build step.
